⚙️ Configuration Google Cloud (Client ID)

🔒 Le mot de passe de chiffrement n'est jamais envoyé à Google. Il chiffre vos données côté navigateur. Si vous le perdez, vos sauvegardes Drive seront irrécupérables.

❓ Comment obtenir un Client ID Google ?
  1. Aller sur console.cloud.google.com
  2. Créer un projet (ex: "Carnet Santé")
  3. Menu ☰ → APIs & Services → Library
  4. Activer Google Drive API
  5. Menu ☰ → APIs & Services → OAuth consent screen
  6. Choisir "External" → Remplir nom + email → Enregistrer
  7. Dans Test users, ajoutez votre email Google
  8. Menu ☰ → APIs & Services → Credentials
  9. Create Credentials → OAuth client ID → Web application
  10. Authorized JavaScript origins : https://steffprevot196.github.io
  11. Authorized redirect URIs : même URL + /Carnet-Sante/
  12. Copier le Client ID et le coller ci-dessus

⚠️ En mode "Testing", seuls les comptes ajoutés dans "Test users" peuvent s'authentifier. Suffisant pour un usage personnel.
